# Проектные заметки

Пользователь системы — лаборант. Он регистрирует оборудование, выбирает получателя и просматривает состояние выдачи.

Инвентарный номер однозначно идентифицирует прибор. Для каждого прибора можно оформить одну активную выдачу. После возврата прибор снова доступен, а запись о выдаче остаётся в журнале.
